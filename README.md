# Keepsake — Laboratory 9 (Vite + Pug + SCSS)

Static responsive Keepsake landing rebuilt from Lab 7 with Pug templates, modular Sass, PostCSS, optimized image sources and quality tooling. No JavaScript UI frameworks.

## Requirements
Node.js 20+ and npm. Open the folder in WebStorm and run:

```bash
npm install
npm run dev
npm run build
npm run preview
npm run images
npm run format
npm run lint
```

## Structure
- `src/pages/index.pug`: page entry extending `src/layouts/main.pug`
- `src/components`: header, footer and individual sections
- `src/data/content.pug`: arrays for repeated content
- `src/mixins/ui.pug`: `btn`, `icon`, `picture`, `work-card`, `panel`
- `src/styles/abstracts`: Sass tokens, maps, functions and mixins
- `src/styles/base`, `layout`, `components`: Sass modules with `@use`/`@forward`
- `image-sources`: original generated artwork, source for `npm run images`
- `public/images`: generated 400w/800w AVIF, WebP and JPEG
- `.github/workflows/deploy.yml`: GitHub Pages deployment workflow

## Toolchain
Vite builds and minifies; Vituum + Pug generate HTML; Sass compiles SCSS; PostCSS Autoprefixer adds browser-specific prefixes according to `.browserslistrc`; Sharp produces responsive images; Prettier formats Pug/SCSS/JS; Stylelint checks SCSS; Husky + lint-staged checks staged changes before commit.

Browsers: last 2 versions of Chrome, Firefox, Edge, Safari and iOS Safari.

## Deployment
Create a **new** repository named `landing-keepsake-vite`, commit the project in meaningful stages, push to `main`, then in GitHub Settings → Pages select **GitHub Actions** as the source. The deployment URL will be `https://YOUR_USERNAME.github.io/landing-keepsake-vite/` (replace `YOUR_USERNAME`). Do not commit `node_modules` or `dist`.

## Image optimization
Original generated illustrations are stored in `image-sources/`. Optimized 400w/800w variants are included. Re-run `npm run images` after changing originals. AVIF/WebP/JPEG sizes depend on the source; compare with `du -sh image-sources public/images` or `find ...`.

## Important limitations
This is an original illustrated reconstruction of the Lab 7 layout, **not a pixel-perfect copy of Figma assets**. Actual browser rendering and W3C validation require running the project. GitHub repository and Pages publication must be completed in your account. `package-lock.json` is generated by `npm install` and must be committed.
